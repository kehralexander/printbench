# PrintBench v0.7.4-oidc.8

Fork build of PrintBench 0.7.4 (OIDC sign-in, adding files to models, G-code
previews, print-queue details, Spoolman inventory, printer status, job tracking
and the follow-up list) that merges the Models and Search pages.

## Highlights

- **One Models page.** Browsing and searching are the same page now: the search
  box, sort and filters sit above the model grid, and an empty search box is
  the whole library A–Z, as Models was before. The separate Search entry is gone
  from the menu. On a narrow screen the filters fold away above the grid.
- **Paging that stays cheap.** In every order except "best match" for a typed
  query, Previous and Next step by cursor, so a page deep into a large library
  costs no more than the first. A typed query in best-match order keeps
  numbered pages. Changing a filter or the sort goes back to page one.
- **Faster pages generally.** Thumbnails, formats and dimensions are now looked
  up for the 48 models on the page only, rather than for every match before the
  page was cut. On a 20,000-model library a page went from about 80 ms to about
  6 ms.

## Upgrade notes

- No migrations and no new settings.
- Old `/search` links and bookmarks redirect to `/models` with the same query
  and filters. Bookmarks of a later page of the old Models list open on page
  one.
