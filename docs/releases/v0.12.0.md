# PrintBench v0.12.0

PrintBench 0.12.0 makes a full print queue readable at a glance. What is on
each printer gets a card of its own at the top, a model's parts are grouped
into one card, and every row is down to one button and a menu.

## Highlights

### What is printing now

- **A card per print on a printer**, above the rest of the queue. It shows the
  model and part, a progress bar, the percentage, the time left and when the
  print should be done. **Printed** and the ⋯ menu sit beside them.
- **The printer's loaded slots in the card's footer.** It also says which
  waiting part to start next on that printer, and how many waiting parts match
  what is loaded. Waiting rows no longer repeat "Loaded on Kobra X, slot 2"
  each on a line of their own.

### Grouped by model

- **One card per model and requester.** Requests for the same model for the
  same person, or the same customer, show as one card. The model, requester,
  colours, remaining time and weight appear once, along with the total price
  for whoever does the charging. Each part has its own line, with name,
  filament and slot, time, weight and price in aligned columns.
- **Part names from the G-code file name.** The slicer's suffix is dropped, so
  `Base - Standard (up to 95ml)_PLA_0.16_5h18m25s.gcode` reads as
  "Base - Standard (up to 95ml)".
- **Send next** on a group's card sends its first waiting part that can be
  sent. A part that is on the printer stays in its group, highlighted and
  marked "printing now", so the group's count still adds up.
- **Drag a whole group, or the parts within one.** The arrow keys on a handle
  move it as well.
- **Group: By model / None** next to the sort switches back to one row per
  request. The choice is kept in the URL (`?group=none`).

### Less on every row

- Each row has one button for its next step and a ⋯ menu for the rest:
  - a waiting request shows **Send & start**, or **Start** when its file cannot
    be sent;
  - a request on the printer shows **Printed**;
  - a closed request shows **Reopen**.
- The menu holds Send & start, Mark as on the printer, Back to queue, Mark
  printed, Edit, Change link, Status link, Cancel and Remove.
- "for <name>" is left out when every request in view is for the same person.
- Filament, slot and spool are shown on one line, and the spool only gets a
  line of its own when it will run short.

## Upgrade notes

- **No database migration, environment change or backup-format change.** No
  action is needed.
- **Queue order when dragging in the grouped view.** Dragging there saves a
  model's parts next to each other, in the order shown. A queue whose parts
  for one model were spread out is reordered that way the first time something
  is dragged. Nothing is reordered just by viewing the queue. To keep the old
  order, switch Group to None before dragging.
- Buttons that used to be on every row (Start, Printed, Change link and Edit)
  are now in each row's ⋯ menu.
- If upgrading from an earlier version, also read the
  [v0.11.0 upgrade notes](v0.11.0.md) and the earlier release notes linked
  there.
