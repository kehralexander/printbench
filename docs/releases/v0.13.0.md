# PrintBench v0.13.0

PrintBench 0.13.0 rebuilds the model page around what you do with a model:
pick a plate and print it, find the part you need among many files, and look
at it without scrolling away from its row.

## Highlights

### Plates ready to print

- **A strip of sliced plates** at the top of the page, each with its picture.
  The picked plate's print time, filament, weight and logged prints show
  beneath it, with **Send**, **Queue**, Open in… and Download beside them.
- The slicer's full read of a plate (timeline, stops, footprint on the bed)
  opens in a side panel from there.

### Files grouped into parts

- **Mesh files are grouped by part, with their variants.** A download of forty
  STLs named like `Detergent Dispenser - Dosing Mechanism 50ml.stl` reads as a
  handful of parts, each listing its sizes or options. The model's name
  repeated at the start of every file is left out. Files that do not fit the
  pattern keep a row of their own, and every action still uses the file's real
  name.
- **Filter files…** above the table narrows it by name.
- **Delete a single file** from a model, with **Delete from disk…** in its
  menu. The file is removed from storage and
  the index, and the model's file count and size are updated. The last file of
  a model, single-file models and files in read-only libraries cannot be
  deleted.
- **Choose the model's thumbnail** from its images and from files with a
  render, with **Use as thumbnail** in a file's menu. The chosen file is
  marked, and **Use the automatic thumbnail** on it goes back.

### Preview beside the page

- **The model's picture and 3D view sit in a rail** beside the page, and
  follow the files table: picking a mesh loads it in the viewer, picking an
  image shows that image. The caption names the file and carries its actions.
- Long descriptions are cut to a few lines, with a toggle to read the rest.
- On very wide screens the page uses more of the width.

## Upgrade notes

- **No database migration, environment change or backup-format change.** No
  action is needed.
- Deleting a file from a model removes it from storage. It is not kept in a
  trash; restore it from a backup if needed.
- If upgrading from an earlier version, also read the
  [v0.12.0 upgrade notes](v0.12.0.md) and the earlier release notes linked
  there.
