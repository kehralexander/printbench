# PrintBench v0.7.4-oidc.9

Fork build of PrintBench 0.7.4 (OIDC sign-in, adding files to models, G-code
previews, print-queue details, Spoolman inventory, printer status, job tracking,
the follow-up list and the merged Models page) that adds KX-Bridge as a printer
type.

## Highlights

- **KX-Bridge printer type.** For an Anycubic Kobra X behind KX-Bridge. It is
  Moonraker for everything else (status, ACE slots, job tracking, fetching files
  back), but "Send & start" now names the ACE slot to print from. The bridge no
  longer stops to ask in its own web page when several slots hold the same
  material.
- **The slot is picked for you.** For a queue request: its Spoolman spool if
  that is loaded, otherwise its material and colour. From a model page, or for
  a multi-colour file: the colour and material each tool was sliced with. Each
  tool gets its own slot.
- **Asked here when it is not clear.** If more than one loaded filament could be
  meant, or the one asked for is not loaded, the send popover shows the loaded
  slots with the best guess selected. Nothing is sent until you press Start.
- OctoPrint, PrusaLink and plain Moonraker printers send exactly as before.

## Upgrade notes

- One migration, `0022_kx_bridge`, adds the `kx-bridge` printer type. It only
  adds a value, so it is safe on a running database.
- Existing printers stay as they are. To use the slot choice, change the
  printer's Type to "KX-Bridge" under Manage → Printers.
- Needs a KX-Bridge with `POST /printer/print/start` filament assignments and
  `GET /kx/filament/slots` (0.9.x).
