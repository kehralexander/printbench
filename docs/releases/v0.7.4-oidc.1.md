# PrintBench v0.7.4-oidc.1

Fork build of PrintBench 0.7.4 that adds optional OpenID Connect single
sign-on.

## Highlights

- Sign in with any OpenID Connect provider (Authentik, Keycloak, …) through
  Better Auth's generic OAuth plugin. The login page shows a
  "Sign in with <name>" button when SSO is configured.
- An SSO sign-in attaches to the existing account with the same email, so
  current users keep their role and libraries.
- New users are refused unless `OIDC_ALLOW_SIGNUP=true`, in which case they are
  created as viewers. SSO sign-ins are recorded in the audit log.

## Upgrade notes

- No database migrations. SSO stays off until `OIDC_ISSUER`, `OIDC_CLIENT_ID`
  and `OIDC_CLIENT_SECRET` are set; `OIDC_NAME` (button label, default `SSO`)
  and `OIDC_ALLOW_SIGNUP` are optional.
- Register `<BETTER_AUTH_URL>/api/auth/callback/oidc` as the redirect URI with
  scopes `openid email profile`.
