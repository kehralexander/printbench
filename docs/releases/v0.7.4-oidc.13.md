# PrintBench v0.7.4-oidc.13

Fork build of PrintBench 0.7.4 (OIDC sign-in, adding files to models, G-code
previews, print-queue details, Spoolman inventory, printer status, job tracking,
the follow-up list, the merged Models page and the KX-Bridge printer type) where
every page follows one design system.

## Highlights

- **One way to edit.** Creating or editing a spool, a filament, a logged print,
  queue requests and invitations happens in a dialog with Cancel and the action
  on the right. Only in-place renames stay inline.
- **Every list sorts the same way.** One sort control, on its own row right
  above the list, on every page, including a model's files, a spool's history
  and print statistics.
- **Less repetition.** Queue rows keep their main actions and put the status
  link, cancelling and removing under "···"; the status link opens with a QR
  code. A spool's page shows one history of stock changes and prints. Filament
  names no longer repeat themselves, Health lists each file once, and the
  same weight or count is not shown twice.
- **Shared pieces.** Colour swatches, stat tiles, tables, badges, empty states,
  page headers and dialogs are one component each, so they look alike
  everywhere, in light and dark mode and on phones.
- **Consistent wording.** Dates read "1 Nov 2026", durations "6h 52m", and print
  outcomes show an icon with a word. Destructive actions are red.
- **SSO-only sign-in.** When OIDC is set up, admins can hide the email and
  password fields on the sign-in page. `/login?password=1` still shows them.
- A themed "Nothing here" page for unknown addresses.
- Server logs are listed in the order they were written.

## Upgrade notes

- No migrations.
- The new "hide password sign-in" setting is off by default.
