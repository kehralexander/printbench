# PrintBench v0.7.4-oidc.2

Fork build of PrintBench 0.7.4 with optional OpenID Connect sign-in (see
v0.7.4-oidc.1), adding files to existing models, and G-code previews.

## Highlights

- **Add files to a model.** The model page has an "Add files" button (members
  and up, writable libraries only) that uploads straight into that model's
  folder: more meshes, sliced G-code, images, documents, or a ZIP that is
  unpacked into the model. A file with a name already in use is stored as
  `name (1).ext`; nothing is ever replaced. Folders inside a drop are kept only
  when they are ones a model already absorbs (`stl/`, `presupported/`,
  `images/`, …) and flattened otherwise, so an upload never splits a model.
- **Single-file models get a folder.** Adding files to a loose `dragon.stl`
  first moves it into `dragon/dragon.stl` after confirmation. The model keeps
  its id, so tags, notes, print history, collections and share links stay.
  Recorded in the audit log as "Moved a single-file model into its own folder".
- **G-code previews.** The preview image PrusaSlicer, SuperSlicer, Orca and
  Cura embed in `.gcode`, and the thumbnail blocks of Prusa binary `.bgcode`,
  become the file's thumbnail. Sliced files show it in the file list, and it
  stands in as the model's preview when nothing else rendered. Mesh renders and
  images still win.

## Upgrade notes

- No database migrations and no new settings.
- Existing G-code files pick up their previews on the next library scan.
