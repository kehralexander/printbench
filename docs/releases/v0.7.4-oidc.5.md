# PrintBench v0.7.4-oidc.5

Fork build of PrintBench 0.7.4 (OIDC sign-in, adding files to models, G-code
previews, print-queue details, Spoolman inventory) with a live printer status
page.

## Highlights

- **Printer status page.** A new "Printer status" page shows every configured
  print host live: idle or busy, the file on the printer, progress in percent,
  time elapsed, time remaining and the clock time it should be done, plus
  layer and nozzle/bed temperatures where the printer reports them. It
  refreshes every ten seconds while the tab is visible.
- **Works with KX-Bridge.** Moonraker hosts are read through
  `/printer/objects/query`; KX-Bridge's own countdown (`remain_time`) is used
  as the time remaining. Plain Klipper, which has none, gets an estimate
  extrapolated from progress once a print is past 2%, marked with "~".
  OctoPrint and PrusaLink hosts are supported too.
- **Linked to the library.** When a sliced file in the library has the name
  the printer reports, the job links to its model and shows the G-code
  thumbnail.
- **Fails soft.** A printer that does not answer within 5 s shows as offline
  with the reason; the rest of the page is unaffected.
- **Fix:** queue times ("on the printer since", "done around") are now shown in
  the browser's timezone instead of the server's.

## Upgrade notes

- No migrations and no new settings. The page lists the printers configured
  under Admin → Printers; add a KX-Bridge as a Moonraker host with its HTTP
  address (for example `http://kx-bridge:7125`).
- Anyone who can view models can see the status page.
