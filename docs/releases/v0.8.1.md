# PrintBench v0.8.1

PrintBench 0.8.1 makes the requester's status page (`/r/<token>`) livelier.

## Highlights

- **The picture prints itself.** The model's picture is larger, and while the
  request prints it fills in from the bottom up as far as the print has got,
  ticking with the progress bar and showing the percentage. A model without a
  picture fills its placeholder the same way.
- **Where it is at a glance.** A Requested → Printing → Ready stepper with the
  time of each step.
- **Progress in the tab.** The browser tab reads "71% · Desk organizers" while
  printing, and starts with Waiting, Printing, Ready or Cancelled otherwise.
- **Filament colour.** A swatch next to the material and colour.
- **One icon per copy.** Requests for several copies show which are printed,
  which is on the printer and which are still to come.
- Animations stop for visitors who prefer reduced motion.

## Upgrade notes

- No additional upgrade action is needed when upgrading from v0.8.0. This
  release adds no database migrations, environment changes or backup-format
  changes. Follow the normal backup and container upgrade procedure.
- If upgrading from an earlier version, also read the
  [v0.8.0 upgrade notes](v0.8.0.md) and the earlier release notes linked there.
