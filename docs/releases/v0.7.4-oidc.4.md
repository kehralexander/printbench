# PrintBench v0.7.4-oidc.4

Fork build of PrintBench 0.7.4 (OIDC sign-in, adding files to models, G-code
previews, print-queue details) that can use Spoolman as the filament inventory.

## Highlights

- **Spoolman as the inventory.** Set `SPOOLMAN_URL` and Spoolman owns spools
  and stock. PrintBench only reads from it; whatever reports usage to Spoolman
  (a printer bridge, Moonraker, Home Assistant) stays the only thing that
  deducts filament.
- **Read-only Filaments page.** Spools grouped by filament with vendor,
  material, colour, grams left of the total, location, low/empty markers and a
  link to each spool in Spoolman. Archived spools are hidden unless asked for.
- **Built-in inventory off.** While Spoolman is configured, PrintBench's own
  filament and spool pages and actions are disabled and the print log no longer
  records spool usage. Existing inventory data is kept untouched and returns if
  `SPOOLMAN_URL` is removed.
- **Spools in the print queue.** The material and colour picker lists
  Spoolman's spools, grouped by location. A request remembers its spool and
  shows it live ("Spool #17 · 894 g left"), and warns when the chosen G-code's
  filament weight times the quantity is more than the spool has left.
- **Fails soft.** Spoolman is read server-side with a 3 s timeout and a 60 s
  cache. When it is unreachable the Filaments page says so, the picker offers
  free text only, and queue rows simply show no spool details.

## Upgrade notes

- One migration adds `spoolman_spool_id` and `filament_g` to `print_requests`,
  dated directly after the previous fork migration.
- `SPOOLMAN_URL` is optional, for example `http://spoolman:7912`. Spoolman needs
  no authentication; PrintBench never writes to it.
