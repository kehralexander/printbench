# PrintBench v0.7.4-oidc.11

Fork build of PrintBench 0.7.4 (OIDC sign-in, adding files to models, G-code
previews, print-queue details, Spoolman inventory, printer status, job tracking,
the follow-up list, the merged Models page and the KX-Bridge printer type) whose
pages keep themselves up to date while something is happening.

## Highlights

- **Progress that moves.** On the printer status page, the dashboard and a
  requester's status link, the progress bar, elapsed and remaining time tick on
  every second between refreshes instead of jumping every few seconds. A paused
  print stays still, and a running print is never shown as done before the
  printer says so.
- **The dashboard follows the printers.** It re-reads them every 20 seconds, as
  often as the worker does.
- **Pages catch up when background work finishes.** When a library scan, a
  health check or model processing completes, the page you are on refreshes,
  so the results show without a reload.
- **Pages with something unfinished refresh themselves.** A model page while
  its previews are being made or one of its prints is still running, and the
  print history while a running print is on screen.
- "Done around" times now count from when the printer was read, not when the
  page was drawn.

## Upgrade notes

- No migrations.
- The printer status page shares each printer reading between everyone
  looking at it for five seconds, so several open tabs no longer multiply the
  requests to the printers.
