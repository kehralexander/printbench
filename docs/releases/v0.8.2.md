# PrintBench v0.8.2

PrintBench 0.8.2 polishes the requester's status page (`/r/<token>`).

## Highlights

- The model's picture is centred above the request.
- The stepper's connecting lines stop short of the step dots, so they no
  longer run across the tick or the step numbers.
- The README says what this fork adds to the original PrintBench, and its
  version badge shows this fork's latest release.

## Upgrade notes

- No additional upgrade action is needed when upgrading from v0.8.1. This
  release adds no database migrations, environment changes or backup-format
  changes. Follow the normal backup and container upgrade procedure.
- If upgrading from an earlier version, also read the
  [v0.8.1 upgrade notes](v0.8.1.md) and the earlier release notes linked there.
