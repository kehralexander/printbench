# PrintBench v0.7.4-oidc.3

Fork build of PrintBench 0.7.4 (OIDC sign-in, adding files to models, G-code
previews) with a more complete print queue.

## Highlights

- **Edit queue requests.** Every open request has an edit dialog for its
  wording, quantity, priority, due date, requester, notes, material and
  colour, the file to print and the print time.
- **Notes, material and colour when queueing.** The model page's "Queue" and
  the bulk "Add requests" box take notes and a material and colour. The picker
  lists the filaments on hand ("PETG · Galaxy Black") with "Other…" for
  anything else. Colour names are stored and carried into the print history.
- **Which plate.** "Queue" on a model with several printable files asks which
  one, defaulting to the only sliced plate when there is just one.
- **Estimated print time, per print.** Typed as "2h 10m", "2:10" or minutes.
  Pre-filled, but never overwritten, from the chosen G-code's slicer estimate,
  the model's only G-code file, or the median of earlier prints. The queue shows
  "~6h 30m (3 × 2h 10m)" for several copies and totals the open queue in the
  header ("~14h of printing").
- **Start time.** "Start" records when a print went on the printer: the row
  shows "done around 14:30", and "Printed" now gives the print history a real
  duration, which in turn improves later estimates.

## Upgrade notes

- One migration adds `color_name`, `estimated_min` and `started_at` to
  `print_requests`. It is dated directly after upstream's latest migration so
  future upstream migrations still apply; rename the file if a rebase brings an
  upstream `0018_*`.
- Existing requests have no estimate; linking a model to one fills it in.
